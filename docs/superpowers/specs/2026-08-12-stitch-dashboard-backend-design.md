# Stitch 대시보드와 Isolation Forest 백엔드 연결 설계

## 목적

Google Stitch에서 추출한 다섯 개의 HTML 화면을 유지하면서, Case1 진동 데이터와 현재 Isolation Forest 분석 결과를 실제로 조회·재분석할 수 있는 로컬 웹 대시보드로 만든다. 대상 화면은 개요, 진동 분석, 알람 내역, 성능 평가, 모델 설정이다.

## 범위와 전제

- 데이터 원본은 `AI Model Raw Data.xlsx`의 `Case1` 시트이다.
- 분석 결과는 `case1_vibration_anomaly_results.csv`를 기본 조회 대상으로 사용한다.
- 모델 설정을 저장하고 재분석할 때는 동일 원본으로 기존 Python 분석 코드를 다시 실행해 결과 CSV를 갱신한다.
- 초기 버전은 로컬 PC에서 실행한다. 설비의 실시간 수집, 사용자 로그인, 외부 DB, 클라우드 배포는 포함하지 않는다.

## 선택한 구조

Stitch HTML은 화면 구성과 스타일의 출발점으로 사용한다. 각 HTML 화면에 JavaScript를 추가해 FastAPI가 제공하는 JSON 데이터를 불러오고, 카드·표·차트를 실제 값으로 채운다. FastAPI는 기존 분석 코드와 CSV를 연결하는 얇은 계층이며, 모델 로직 자체는 기존 파일을 재사용한다.

```text
브라우저의 Stitch HTML
        ↕ HTTP JSON
FastAPI 웹 서버
        ↕
분석 결과 CSV · 모델 설정 JSON · 원본 Excel
        ↕
기존 Case1 Isolation Forest 분석 코드
```

## 화면별 동작

### 개요

선택 기간을 기준으로 최신 `Vibration`, `short_mean`, 이상 점수, 임계값, 점수 차이, 현재 상태, 확정 경보 수를 보여준다. 추세 데이터에는 진동값·이동평균·정상/이상 평균·경보 표시를 제공한다. `raw_anomaly`는 후보, `confirmed_anomaly`와 `is_anomaly`는 확정 경보로 명확히 구분한다.

### 진동 분석

선택 기간의 진동 시계열, Isolation Forest 점수, 주요 특징량(`short_mean`, `short_std`, `long_mean`, `long_std`, `slope`, `volatility_ratio`, `spike_count`)을 조회한다.

### 알람 내역

선택 기간의 후보 및 확정 경보를 시간, 점수, 유형, 확정 여부로 조회하고 유형별 집계를 제공한다.

### 성능 평가

현재 합성 이상 검증 결과를 읽어 이상 유형별 탐지율과 정상 구간 오탐지율을 표시한다. 이 수치는 실제 현장 고장 검증 결과가 아니라 합성 데이터 평가임을 함께 표시한다.

### 모델 설정

임계값 분위수, 지속 판정 시간, 트리 수, 랜덤 시드, 단기·장기·추세 윈도우를 조회·수정한다. 저장만 하는 동작과 저장 후 재분석 동작을 구분하며, 재분석이 완료된 뒤 화면은 새 결과를 다시 조회한다.

## 데이터 계약

프론트엔드는 화면 단위의 조회 API를 사용한다. 모든 시간 범위 요청은 시작·종료 시각을 전달하며, 경보 수와 목록은 반드시 해당 선택 범위에서 계산한다. 응답에는 화면에서 필요한 최소한의 데이터만 포함한다.

- 요약: 최신 관측치, 임계값, 상태, 선택 구간 경보 집계
- 추세/분석: 시간별 관측값 및 특징량
- 경보: 후보·확정 구분, 이상 유형, 점수
- 성능: 합성 평가 지표
- 설정: 현재 설정값과 재분석 실행 결과

## 오류 처리와 안전성

- 원본/결과 파일이 없거나 형식이 맞지 않으면 화면에 이해 가능한 오류를 반환한다.
- 설정값은 허용 범위와 자료형을 서버에서 검증한다.
- 재분석 도중에는 완료 전의 부분 결과를 노출하지 않으며, 실패하면 기존 결과 파일을 유지한다.
- 설정 변경은 로컬 설정 JSON에 저장한다. 로그인·권한 제어는 이번 범위에 포함하지 않는다.

## 검증 기준

- 다섯 화면이 로컬 서버에서 열리고 API 데이터로 표시된다.
- 선택 시간 범위를 바꾸면 차트·경보 수·알람 목록이 함께 바뀐다.
- 모델 설정을 변경해 재분석한 뒤 결과 CSV와 화면 수치가 갱신된다.
- 기존 Isolation Forest 테스트가 계속 통과하고, API의 대표 응답을 테스트한다.

## 구현 제외 항목

- 실시간 설비/PLC 데이터 수집
- 다중 사용자 인증 및 관리자 권한
- 외부 데이터베이스와 클라우드 배포
- 실제 고장 라벨을 활용한 현장 성능 확정
