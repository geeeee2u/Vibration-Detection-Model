# 역할 기반 대시보드 접근 설계

## 목표

대시보드의 모든 화면에서 로그인 계정과 권한을 표시하고, `administrator`만 모델 설정과 재분석 기능을 사용할 수 있게 한다.

## 사용자와 권한

- `administrator`: 모든 대시보드 화면, 모델 설정 조회·저장·재분석 접근 가능
- `technician`: 개요, 진동 분석, 알람 내역, 성능 평가 접근 가능. 모델 설정은 접근 불가

## 동작 방식

- 좌측 하단 계정 영역을 클릭하면 로그인 또는 계정 전환 창을 연다.
- 서버는 로그인 성공 시 서명된 세션 쿠키를 발급한다.
- 모델 설정 화면과 설정 관련 API는 관리자 세션을 요구한다.
- technician이 모델 설정 메뉴를 클릭하거나 `/settings` 주소를 직접 열면 같은 페이지에서 `해당 계정으로는 접근할 수 없습니다.` 문구를 보여 준다.
- ID와 비밀번호는 `.env`에서만 읽고, `.env`는 Git에 추가하지 않는다. 배포·공유용 키 이름만 `.env.example`에 문서화한다.

## 검증 기준

- administrator 로그인 후 `/settings`와 설정 API 접근이 가능하다.
- technician 로그인 후 `/settings`와 설정 API가 거부된다.
- technician에게는 지정된 한국어 안내 문구가 표시된다.
- 각 페이지의 좌측 하단에 현재 계정과 역할이 표시된다.
